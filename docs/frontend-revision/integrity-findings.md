# Control Integrity Findings

Step A4. Every interactive control on all 35 authenticated routes carries exactly one verdict per execution plan §2.1.

**217 findings.** Verdicts: **91 REAL · 57 READ-ONLY · 27 UNAVAILABLE · 21 REMOVED** (the remainder are compound rows where one control needed two categories). Ownership: **169 frontend, 12 backend** — the overwhelming majority of this product's integrity debt is fixable inside this branch without a schema change.

Method: seven auditors, one per route slice, each required to trace a control to a named export in `src/server-functions/` before calling it REAL. An eighth agent then attacked the results adversarially. Full per-slice reports are in [`audit/`](./audit/); the merged table is below. Controls examined and judged sound are listed in [`audit/_merged-REVIEWED-OK.md`](./audit/_merged-REVIEWED-OK.md) — that list is required evidence under plan A4, not filler.
